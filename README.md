# Task Management System

A REST API built using Spring Boot, Spring Security, JWT Authentication, MySQL and Swagger.

## Features

- User Registration
- User Login
- JWT Authentication
- Role Based Authorization
- Create Task
- Update Task
- Delete Task
- Get Task By Id
- Get All Tasks
- Get Tasks By Status
- Get Tasks By User Id
- Swagger Documentation

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- JWT
- MySQL
- Maven
- Swagger OpenAPI
- Git & GitHub

## API Endpoints

### Auth

- POST /api/auth/register
- POST /api/auth/login

### Tasks

- GET /api/tasks
- GET /api/tasks/{id}
- POST /api/tasks
- PUT /api/tasks/{id}
- DELETE /api/tasks/{id}
